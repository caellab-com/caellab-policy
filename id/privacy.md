### 政策概述

CaelLabID（以下简称"本平台"）是虚舟实验室的统一身份认证系统。我们尊重并保护每一位用户和开发者的隐私。

本隐私政策说明我们在提供身份认证服务过程中，如何收集、使用、存储和保护相关信息。

使用本平台即表示你理解并同意本政策的约定。如果你不同意，请停止使用本平台。

---

### 我们收集的信息

**注册与账户信息**

注册时你需要提供邮箱地址和密码。密码经加密存储，连我们自己也无法还原。你的用户名和头像等个人资料由你主动填写。

**授权与认证信息**

当你通过 CaelLabID 登录第三方应用时，我们会记录授权关系——包括你授权了哪个应用、授权了哪些权限（scope）、以及授权时间。我们不会记录你在第三方应用中的具体操作。

**OAuth Token 信息**

为维持认证服务正常运行，我们会存储 Access Token 和 Refresh Token 的哈希值（不可逆）。Token 本身不会被我们保存。

**日志信息**

为保障服务安全和排查故障，服务器会记录基础的访问日志，包括 IP 地址、访问时间、请求路径、浏览器类型等。这些日志不与你的个人身份直接关联。

### 我们如何使用信息

- **提供身份认证服务**：验证你的身份、管理授权关系、签发和验证 Token；
- **安全防护**：识别异常登录、暴力破解、自动化攻击等行为，保护平台和用户账号安全；
- **服务优化**：分析使用数据以改进平台性能和用户体验；
- **合规响应**：在法律法规要求或有权机关依法提出请求时，配合提供必要信息。

我们不会将你的信息用于营销、广告推送或用户画像分析，也不会出售你的个人信息。

---

### 跨应用隐私保护

CaelLabID 为每个应用独立生成用户标识（`subject_id`）。这意味着：

- 同一个用户在不同应用中拥有不同的标识
- 应用之间无法通过 CaelLabID 的标识关联同一用户
- 你在应用 A 中的身份信息不会被应用 B 获取

这是我们的核心隐私设计原则。

### 信息共享

我们严格限制信息共享，仅在以下情形下向第三方提供信息：

- **你的明确授权**：当你在授权页面同意将信息共享给某个应用时；
- **服务提供商**：向提供服务器托管、技术支持等服务的合作方共享必要信息，且要求其遵守同等保护标准；
- **法律法规要求**：在法律法规强制要求或有权机关依法提出请求时，配合提供必要信息；
- **权益保护**：为保护本平台、用户或公众合法权益免受侵害，在必要范围内披露信息。

具体第三方信息共享情况请参阅[第三方信息共享清单](/id/third-party-sharing)。

### 你的权利

**查看与管理**

你可以随时登录 [CaelLabID](https://id.caellab.com) 查看你的账户信息、管理已授权的第三方应用，并在 [仪表盘](https://id.caellab.com/dashboard) 中撤销对任何应用的授权。

**注销账号**

你可以申请注销 CaelLabID 账号。注销后：

- 你的账户信息和授权关系将被删除
- Access Token 和 Refresh Token 将立即失效
- 你在各应用中的标识（`subject_id`）将被删除
- 第三方应用可能仍保留其自身系统中的登录状态

注销申请请发送邮件至 [id@caellab.com](mailto:id@caellab.com)，我们将在 **7 个自然日**内处理。

**数据导出**

如需导出你的账户数据，请通过上述邮箱联系我们。

### 信息存储与保护

- **存储地点**：用户数据存储在虚舟实验室自有服务器（通常位于香港地区），通过 [Cloudflare](https://www.cloudflare.com/) 进行网络分发与安全防护；
- **加密保护**：所有数据传输强制使用 HTTPS 加密；密码等敏感信息采用哈希加密存储；
- **Token 安全**：Token 以 SHA-256 哈希值存储，服务端不保留明文；
- **保留期限**：账户信息保留至账号注销；访问日志保留不超过 90 天；授权记录保留至授权撤销或账号注销。

### 儿童隐私保护

我们不会主动收集用户的年龄信息。如果你是儿童，请在监护人指导下使用本平台并完成注册。如果我们发现无意中收集了儿童的个人信息，将立即删除。
